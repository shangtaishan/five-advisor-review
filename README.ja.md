# Five-Advisor Review

**言語：** [中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

アイデア、提案、企画、意思決定、ビジネス構想を多面的にストレステストするための Skill です。

複数の助言者の一致を事実とは扱わず、五つのロールプロンプトを五つの独立モデルであるかのようにも扱いません。このフレームワークは、まず隔離された一次判断を作成し、匿名の相互レビューと合意のストレステストを行います。最後に議長が、検証行動を伴う可逆的な推奨を示します。

> 中国語 README を基準版とします。README、方法論、コア設計、貢献ガイドは中国語・英語・日本語で維持します。機能または方法論に重要な変更がある場合は、同じ変更内で三言語の対応文書を更新してください。

## 解決する問題

多視点のレビューに見えても、実際には同じ推論経路を繰り返していることがあります。本プロジェクトでは、レビューを次の五つの方法に分けます。

1. **反証者**：失敗を前提に、起こりやすい失敗メカニズムを逆算します。
2. **本質を問う人**：目標、因果関係、未検証の仮定を分解します。
3. **機会発見者**：隣接する文脈から見落とされた代替案を探します。
4. **素人の視点**：一般の人の理解、信頼、価格、手間を問います。
5. **無情な実行者**：最初の阻害要因を見つけ、今日完了できる検証行動に落とし込みます。

さらに、合意が単一の仮定に依存していないかを確認し、最強の反論を明示し、議長に重要な異論を投票で押しつぶさず保持させます。

## クイックスタート

1. [`skill/`](skill/) を Codex Skills ディレクトリへコピーするか、実行環境からインポートします。
2. 会話で次のように使います。

   ```text
   $five-advisor-review を使って、このアイデアをレビューしてください：…
   ```

3. 低コストで可逆的な案にはクイックモードを使います。中・高リスク、不可逆、または重要な事実が不明な意思決定には、検証基準付きの完全モードを使います。

完全な運用指示は [`skill/SKILL.md`](skill/SKILL.md) を参照してください（現在は中国語です）。

## コア原則

- **合意は証拠ではありません。** 一致は注目の優先順位を上げるだけであり、信頼性を上げるのは検証です。
- **未知を明示します。** 検証できないデータ、事例、基準値は未知として示し、もっともらしい数字で埋めません。
- **実験閾値は業界基準ではありません。** 未検証の数値には `[実験閾値]` を付け、リスク管理上の目的を示します。
- **独立性を偽装しません。** 同一モデルが作る五つの視点は手続き上隔離されているだけで、複数モデルの証拠ではありません。
- **賭ける前に可逆的に動きます。** 高リスクまたは不可逆な判断では、最初に検証またはリスク分離を行います。

## 利用に適する場面

ビジネスモデル、製品提案、コンテンツ企画、戦略選択、アーキテクチャのトレードオフ、研究仮説、リソース配分に利用できます。

単一の事実質問、純粋な翻訳、純粋な創作、実質的なトレードオフのない問題、すでに明示的に許可された直接実行には使用しません。
