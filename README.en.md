# Five-Advisor Review

**Languages:** [中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

A multi-perspective decision stress-test Skill for ideas, proposals, topics, decisions, and business concepts.

It does not treat agreement among several advisors as fact, nor does it pretend that five role prompts are five independent models. The framework first produces isolated first-round judgments, then runs anonymous peer review and a consensus stress-test. A chair then issues a reversible recommendation paired with a validation action.

> The Chinese README is the canonical version. The README, methodology, core design, and contribution guide are maintained in Chinese, English, and Japanese. When a feature or methodological change is material, update all three corresponding documents in the same change.

## What it solves

Many idea reviews appear to offer several viewpoints while repeating one reasoning path. This project separates the review into five methods:

1. **Contrarian**: pre-mortems likely failure mechanisms.
2. **First-principles questioner**: breaks down goals, causal links, and untested assumptions.
3. **Opportunity finder**: searches adjacent contexts for overlooked alternatives.
4. **Layperson**: asks about comprehension, trust, price, and hassle from an ordinary person's perspective.
5. **Ruthless executor**: identifies the first blocker and turns the proposal into a validation action that can be completed today.

The framework then checks whether consensus shares a single source, states the strongest counterargument, and requires the chair to preserve material dissent rather than flatten it with a vote.

## Quick start

1. Copy [`skill/`](skill/) into your Codex Skills directory, or import it through your runtime.
2. In a conversation, use:

   ```text
   Use $five-advisor-review to review this idea: …
   ```

3. Low-cost, reversible ideas use quick mode. Medium/high-risk, irreversible, or factually uncertain decisions use full mode with validation criteria.

See [`skill/SKILL.md`](skill/SKILL.md) for the complete operating instructions (currently in Chinese).

## Core principles

- **Consensus is not evidence.** Agreement raises attention priority; validation raises credibility.
- **Make unknowns explicit.** Unverifiable data, cases, and benchmarks must be marked unknown, not replaced with professional-sounding figures.
- **An experiment threshold is not an industry benchmark.** An unverified number must be marked `[Experiment threshold]` and tied to a risk-control purpose.
- **Do not fabricate independence.** Five perspectives generated by one model are procedurally isolated, not multi-model evidence.
- **Make a reversible move before a bet.** The first step for a high-risk or irreversible decision should validate or isolate risk.

## Appropriate use

Use it for business models, product proposals, content topics, strategic choices, architecture tradeoffs, research hypotheses, and resource allocation.

Do not use it for a single factual question, pure translation, pure creative work, a problem with no real tradeoff, or direct execution already explicitly authorized.
