# 方法论：从多角色回答到决策压力测试

## 目标

五顾问审查不是让五个角色轮流发表意见，而是用不同的推理方法暴露同一方案的脆弱处、遗漏机会与行动阻塞点。最终产出必须帮助用户决定：推进、附条件推进、暂缓还是放弃；以及下一步验证什么。

## 流程

```text
审查底稿
  → 五份隔离的首轮意见
  → 匿名交叉审查
  → 共识压力测试
  → （高风险且仍有关键分歧时）对抗复核
  → 主席裁决与验证行动
```

### 1. 审查底稿

先固定提案、目标、对象、约束、本次决策和关键未知。这样每一位顾问审查同一件事，避免有人讨论愿景、有人讨论执行而无法比较。

### 2. 五份隔离首轮意见

每位顾问只读取审查底稿，不回应已经生成的意见。隔离的目的不是制造虚假的模型独立性，而是降低首个观点锚定后续观点的概率。

| 顾问 | 推理方法 | 主要产出 |
|---|---|---|
| 反驳者 | 逆向预演 | 最可能的失败机制、反例、长期副作用 |
| 本质追问者 | 拆解验证 | 会改变决策的因果假设与“凭什么” |
| 机会发现者 | 类比扩展 | 被遗漏的替代路径及其排序 |
| 外行人 | 朴素追问 | 普通用户的理解、信任、价格和麻烦成本 |
| 无情执行者 | 依赖图 | 第一阻塞点、当天动作、产出物、停止条件 |

完整模式中，每位顾问还要说明“关键依据、最大未知、反转证据”。这比让顾问自报“高/中/低置信度”更可审计。

### 3. 匿名交叉审查

首轮意见重新排列为候选 A 至 E，不展示角色身份。互审只评估论证：哪项最能改变决策、哪项最弱、分歧是价值权衡还是事实纠错，以及五份意见共同遗漏了什么。

### 4. 共识压力测试

共识必须经过两道检验：

- **同源检查**：多数意见是否只是依赖同一条假设或推理路径？若是，它们只是一票被重复表达的意见。
- **魔鬼代言人**：什么是推翻当前共识的最强单条论证？若该反驳仍有不可忽略的成立概率，必须带入主席裁决。

### 5. 主席裁决

主席不是第六位顾问。其职责是编辑、裁判与行动整合：保留证据充分的异议，区分价值权衡和事实错误，明确阻塞项，并把关键未知变成验证动作。

裁决只出现一次，且必须放在顾问独立意见和互审之后。

## 风险与输出模式

| 风险 | 常见情形 | 输出 |
|---|---|---|
| 低 | 低成本、可逆、可短期验证 | 快速模式：每位顾问一句，给一个低成本验证动作 |
| 中 | 中等投入、架构或性能取舍 | 完整模式：隔离意见、互审、压力测试、验证标准 |
| 高 | 合规、安全、声誉、数据丢失、不可逆或关键事实不明 | 完整模式 + 强验证；必要时对抗复核 |

用户可以要求更短的输出，但不能通过“快速模式”关闭高风险护栏。

## 证据标签

| 标签 | 含义 |
|---|---|
| `[已核验事实]` | 已通过可靠来源或实际材料核验 |
| `[用户提供]` | 来自用户输入，尚未独立核验 |
| `[逻辑推断]` | 从已知材料得出的推理 |
| `[关键未知]` | 缺失且可能改变结论的信息 |
| `[实验阈值]` | 为控制试错成本而设的临时门槛，不是行业基准 |

## 高风险对抗复核

只有高风险场景、且压力测试后仍存在关键分歧时才需要第三轮。它的目标不是让意见收敛，而是让每个立场面对最强反驳后更新依据、未知和反转证据。
