# 核心设计与研究边界

## 设计问题

“多智能体/多角色审查”常见的失效模式包括：

1. **伪独立**：同一模型换五种语气，实际沿用同一条推理路径。
2. **虚假共识**：把五次重复的猜测当作五份证据。
3. **伪精确**：用没有来源的转化率、样本量或成功概率制造专业感。
4. **角色漂移**：机会发现者开始执行，执行者开始替用户做价值判断。
5. **主席越权**：综合者引入前面没有出现的新事实，或无声丢弃强异议。
6. **不可落地**：审查很精彩，却没有当天可完成的验证动作和停止条件。

## 对应护栏

| 失效模式 | 机制 |
|---|---|
| 伪独立 | 统一审查底稿 + 首轮隔离 + 不声称多模型独立 |
| 虚假共识 | 匿名互审 + 同源检查 + 魔鬼代言人 |
| 伪精确 | 证据标签 + `[实验阈值]` 标识 + 无来源即未知 |
| 角色漂移 | 每位顾问绑定一种推理方法和明确职责边界 |
| 主席越权 | 只能综合已有事实前提；补充验证动作须回溯到已识别未知 |
| 不可落地 | 无情执行者的依赖图 + 主席验证标准、检查点和停止条件 |

## 为什么不使用顾问自报置信度

角色自报“高/中/低置信度”往往只衡量语言语气，不能衡量结论可靠性。框架改为记录：

- 关键依据是什么；
- 最大未知是什么；
- 哪条新证据会让结论反转。

主席的置信度只能由证据质量、推理路径独立性、关键未知与决策可逆性综合决定。

## 为什么“少数意见”是条件项

少数意见很重要，但不存在真实少数意见时，强制输出它会诱导模型编造反对观点。正确做法是：

- 有证据充分的少数意见：显式保留；
- 无少数意见：记录最强反驳是否经受检验；
- 不把为了平衡而写的反对意见当作真实分歧。

## 局限

- 这是一种认知与流程工具，不替代法律、医疗、财务、安全等专业意见。
- 它不能自动取得真实世界证据；检索、访谈、实验和数据检查仍需实际完成。
- 程序性隔离只能降低锚定效应，不能消除同一模型或同一资料源的系统性偏差。
- 输出质量受审查底稿质量约束。关键对象、约束或目标不清时，结论应降低置信度而非补写假设。

## 可研究的方向

1. 比较隔离首轮与顺序讨论对假设多样性的影响。
2. 测量同源检查是否降低“重复理由被计为多份证据”的比例。
3. 评估 `[实验阈值]` 标识是否能减少模型编造行业标准。
4. 用真实决策回测主席裁决的校准度、可逆性和验证成本。
5. 比较单模型隔离、真实多代理与人机混合评审的收益/成本比。
