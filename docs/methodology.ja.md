# 方法論：ロール回答から意思決定ストレステストへ

**言語：** [中文](methodology.md) · [English](methodology.en.md) · [日本語](methodology.ja.md) · [Français](methodology.fr.md) · [Español](methodology.es.md)

## 目的

Five-Advisor Review は、五つのロールが順番に意見を述べる仕組みではありません。異なる推論方法により、一つの提案の脆弱性、見落とした機会、実行上の阻害要因を明らかにします。最終出力は、進める、条件付きで進める、保留する、やめる、のどれにするかと、次に何を検証するかを決められるものでなければなりません。

## フロー

```text
レビュー概要
  → 隔離された五つの一次見解
  → 匿名相互レビュー
  → 合意のストレステスト
  → （高リスクで重要な不一致が残る場合）対抗再レビュー
  → 議長の判断と検証行動
```

### 1. レビュー概要

提案、目的、対象、制約、今回の判断、重要な未知を先に固定します。これにより、全ての助言者が同じ対象をレビューし、ある人はビジョン、別の人は実行を語って比較不能になることを防ぎます。

### 2. 隔離された五つの一次見解

各助言者はレビュー概要だけを読み、他の見解には応答しません。隔離はモデルの独立性を偽装するものではなく、最初の意見が後続をアンカーする確率を下げるためのものです。

| 助言者 | 推論方法 | 主な出力 |
|---|---|---|
| 反証者 | 逆算 | 起こりやすい失敗メカニズム、反例、長期的な副作用 |
| 本質を問う人 | 分解検証 | 判断を変え得る因果仮定と「なぜそう言えるのか」 |
| 機会発見者 | 類推 | 見落とされた代替案と順位 |
| 素人 | 素朴な質問 | 理解、信頼、価格、手間に関する一般利用者の問い |
| 無情な実行者 | 依存関係図 | 最初の阻害要因、今日の行動、成果物、停止条件 |

完全モードでは、各助言者は重要な根拠、最大の未知、判断を反転させる証拠も示します。これは高・中・低の自己申告より監査可能です。

### 3. 匿名相互レビュー

一次見解を A から E の候補として並べ替え、ロールの身元を示しません。論証だけを評価します。どの見解が判断を最も変えるか、どれが最も弱いか、不一致が価値のトレードオフか事実訂正か、そして五つが共通して見落としたことは何かを確認します。

### 4. 合意のストレステスト

合意には二つの確認を適用します。

- **同一起源チェック：** 多数の見解が一つの仮定または一つの推論経路に依存していないか。そうであれば、それは繰り返し表現された一票です。
- **悪魔の代弁者：** 形成中の合意を覆す最も強い単一論証は何か。無視できない確率で成り立つなら、議長の判断に持ち込みます。

### 5. 議長の判断

議長は第六の助言者ではありません。編集、裁定、行動の統合を担います。根拠のある異論を残し、価値のトレードオフと事実誤りを分け、阻害要因を明確にし、重要な未知を検証行動に変えます。

判断は独立見解と相互レビューの後に一度だけ示します。

## リスクと出力モード

| リスク | 典型例 | 出力 |
|---|---|---|
| 低 | 低コスト、可逆、短期間で検証可能 | クイックモード：各助言者一文と低コストの検証行動 |
| 中 | 中程度の投資、アーキテクチャまたは性能のトレードオフ | 完全モード：隔離見解、相互レビュー、ストレステスト、検証基準 |
| 高 | コンプライアンス、安全、評判、データ損失、不可逆、重要事実の不足 | 強い検証を伴う完全モード。必要に応じ対抗再レビュー |

ユーザーは短い出力を求められますが、クイックモードで高リスクの安全策を無効にはできません。

## 証拠ラベル

| ラベル | 意味 |
|---|---|
| `[検証済み事実]` | 信頼できる情報源または実際の資料で検証済み |
| `[ユーザー提供]` | ユーザー入力由来で独自検証していない |
| `[論理的推論]` | 既知の資料から導いた推論 |
| `[重要な未知]` | 結論を変え得る欠落情報 |
| `[実験閾値]` | 業界基準ではなく、一時的なリスク管理の閾値 |

## 高リスクの対抗再レビュー

第三ラウンドは、高リスクでストレステスト後も重要な不一致が残る場合だけに使います。目的は意見を収束させることではなく、各立場が最強の反論に向き合い、根拠、未知、反転証拠を更新することです。
